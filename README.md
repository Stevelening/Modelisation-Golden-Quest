## Description :
Il s’agit de modéliser une version simplifiée du jeu Coding Park intitulé [Golden Quest](https://app.codingpark.io/goldenquest), en abordant à la fois ses aspects structurels et comportementaux.

L'objectif de ce projet est d'évaluer :

- Les compétences de modélisation,
- La démarche : la manière dont vous analysez le problème et élaborez vos solutions.

L’exercice est volontairement très guidé : il comprend de nombreuses questions destinées à vous accompagner pas à pas dans la construction du modèle.
